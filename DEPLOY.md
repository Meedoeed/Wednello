# Запуск WEDNELLO в продакшене

Время: ~1 час, не считая модерации ЮKassa (обычно 1–3 рабочих дня).

## 1. Что понадобится

- **Статус для приёма платежей**: самозанятость (до 2,4 млн ₽/год, проще всего начать), ИП на УСН 6% или ООО.
- **Домен**, например `wednello.ru` (reg.ru, nic.ru — 200–900 ₽/год).
- **VPS в РФ** (персональные данные россиян по 152-ФЗ хранятся в России): Timeweb Cloud, Selectel, Yandex Cloud, REG.cloud. Хватит 1 vCPU / 1–2 ГБ RAM / 20 ГБ SSD (~300–600 ₽/мес), Ubuntu 22.04/24.04.
- **Почта на домене**: Яндекс 360 для бизнеса или Mail.ru для бизнеса (бесплатный тариф подходит), создайте ящик `hello@ваш-домен` и пароль приложения для SMTP.

## 2. Сервер

```bash
ssh root@IP-сервера
curl -fsSL https://get.docker.com | sh
git clone https://github.com/Meedoeed/Wednello.git /opt/wednello
cd /opt/wednello
cp .env.example .env
nano .env        # заполните по комментариям
```

Направьте **A-запись** домена (и `www`) на IP сервера, подождите 5–30 минут, затем:

```bash
docker compose up -d --build
docker compose logs -f app      # должно быть «WEDNELLO запущен» и не должно быть предупреждений ⚠
```

Caddy сам получит HTTPS-сертификат Let's Encrypt. Откройте `https://ваш-домен`.

Обновление после изменений в репозитории:

```bash
cd /opt/wednello && git pull && docker compose up -d --build
```

## 3. ЮKassa

1. Зарегистрируйтесь на yookassa.ru, заполните анкету магазина. Для модерации на сайте уже есть: цены (раздел «Цены» на главной), [оферта](/legal/terms), [политика](/legal/privacy), [контакты](/legal/contacts) — заполните `LEGAL_*` в `.env` до отправки на модерацию.
2. После одобрения: **Интеграция → Ключи API** → выпустите секретный ключ → `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` в `.env`.
3. **Интеграция → HTTP-уведомления**: URL `https://ваш-домен/api/billing/yookassa`, события `payment.succeeded` и `payment.canceled`.
4. Чеки 54-ФЗ: самозанятым — подключите «Чеки от ЮKassa» для самозанятых (чек в «Мой налог» формируется автоматически); ИП/ООО — «Чеки от ЮKassa» или онлайн-касса, затем `YOOKASSA_RECEIPT=1` и `YOOKASSA_VAT_CODE` (1 — без НДС).
5. `docker compose up -d` и проверьте тестовым магазином (в ЛК ЮKassa есть тестовый режим с тестовыми картами).

Сервер не доверяет телу уведомления: статус каждого платежа перепроверяется запросом к API ЮKassa, сумма сверяется с ценой тарифа, повторные уведомления не продлевают тариф дважды.

## 4. Почта

`SMTP_HOST`, `SMTP_PORT=465`, `SMTP_USER`, `SMTP_PASS` (пароль приложения), `MAIL_FROM`. Добавьте у регистратора SPF/DKIM записи, которые выдаст почтовый сервис, — иначе письма попадут в спам. Проверка: «Забыли пароль?» на странице входа.

## 5. Аналитика

Создайте счётчик в metrika.yandex.ru, укажите номер в `METRIKA_ID`. Включится автоматически, вместе с уведомлением о cookie. Добавьте сайт в Яндекс Вебмастер и Google Search Console: `sitemap.xml` и `robots.txt` уже отдаются.

## 6. Администрирование

- `ADMIN_EMAILS` — e-mail вашего аккаунта; зарегистрируйтесь на сайте, в меню появится «Статистика сервиса»: выручка, регистрации, конверсия, платежи, популярность шаблонов.
- Выдать Премиум вручную (подарок, блогеру): в `data/db.json` у нужной записи `workspaces` поставьте `"planId": "premium"` и `"planUntil": "2027-12-31T00:00:00.000Z"`, затем `docker compose restart app`.
- Возврат денег делается в ЛК ЮKassa; доступ к тарифу при этом уберите так же вручную.

## 7. Бэкапы

Сервер сам кладёт ежедневную копию базы в `data/backups` (хранит 14). Дополнительно копируйте всю папку `data` (база + фото) за пределы сервера:

```bash
crontab -e
# 15 4 * * * /opt/wednello/deploy/backup.sh /opt/wednello /var/backups/wednello
```

и раз в неделю забирайте архивы в облако (Яндекс Диск, S3 Selectel). Восстановление: остановить `app`, вернуть `data/db.json`, запустить.

## 8. Чек-лист перед рекламой

- [ ] `DEMO=0`, `PUBLIC_URL` с https, в логах нет ⚠
- [ ] Реквизиты в оферте, тестовая оплата прошла, тариф включился, чек пришёл
- [ ] Письмо «Забыли пароль?» доходит и не в спаме
- [ ] Метрика видит визиты, настроены цели: регистрация (`#dashboard`), оплата (`#billing-`)
- [ ] Уведомление в Роскомнадзор об обработке персональных данных (pd.rkn.gov.ru) — обязательно для оператора ПД
- [ ] Своё приглашение на каждом шаблоне открыто с телефона: iPhone Safari и Android Chrome

## Идеи продвижения

- **Отметка на бесплатных приглашениях** — у каждой свадьбы 50–150 гостей, это главный бесплатный канал.
- **Pinterest, VK, Telegram-каналы невест**, свадебные чаты: короткие видео «как оживает приглашение» (запись экрана шаблонов «Кинопремьера», «Полночь», «Сад»).
- **Яндекс Директ** по запросам «онлайн приглашение на свадьбу», «электронное приглашение на свадьбу», «сайт-приглашение на свадьбу».
- **Партнёрства**: свадебные агентства, фотографы и ведущие — промокод или скидка их парам.
- **Avito / Профи**: услуга «сделаю приглашение под ключ» на базе сервиса.
