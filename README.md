# WEDNELLO — онлайн-приглашения на свадьбу

Сервис для пар: красивые анимированные приглашения, личная ссылка каждому гостю, анкета и ответы в одном кабинете. Монетизация — разовая оплата тарифа «Премиум» через ЮKassa.

- **Пара** собирает приглашение в конструкторе с живым предпросмотром, добавляет гостей, рассылает персональные ссылки, видит ответы.
- **Гость** открывает ссылку без регистрации, видит обращение по имени, строит маршрут, добавляет событие в календарь и отвечает на анкету.
- **Вы** видите регистрации, оплаты и популярность шаблонов в разделе «Статистика сервиса».

## Модель заработка

| Тариф | Цена | Что входит |
|---|---|---|
| Бесплатный | 0 ₽ | 1 приглашение, до 40 гостей, бесплатные шаблоны, отметка «Создано в WEDNELLO» |
| Премиум | 1 490 ₽ разово, на год | все шаблоны (включая анимированные), музыка, до 1000 гостей, выгрузка в Excel, без отметки, помощь |

Пейвол стоит на **публикации**: пара бесплатно примеряет и настраивает любой шаблон, видит результат, а платит перед рассылкой. Отметка «Создано в WEDNELLO» на бесплатных приглашениях — бесплатная реклама: каждый гость видит сервис.

Цены, лимиты и состав тарифов — в `shared/core.js → DEFAULT_PLANS`. Для уже работающей базы тарифы хранятся в `data/db.json → plans` (их можно изменить через `PUT /api/plans` от администратора).

## Шаблоны

| Папка | Название | Доступ |
|---|---|---|
| `ivory` | Ivory Letter — конверт с сургучом | бесплатно |
| `minimal` | Минимализм — крупная типографика и фото | бесплатно |
| `garden` | Сад — ботаника, ветви рисуются сами | бесплатно |
| `cinema` | Кинопремьера — проектор и билеты | Премиум |
| `photobooth` | Фотобудка — шторка и фотополоска | Премиум |
| `book` | Книга — переплёт и полароиды | Премиум |
| `midnight` | Полночь — звёздное небо и луна с фото | Премиум |

Шаблон — обычная HTML-страница в `web/public/templates/<папка>`, размеченная атрибутами `data-t` (тексты), `data-v` (имена, обращение к гостю), `data-list` (план дня, палитра), `data-slot` (фото), `data-sec` (разделы), `#rsvpForm` (анкета). Данные раскладывает общий рантайм `templates/_runtime/runtime.js`. Новые лёгкие шаблоны используют `_runtime/kit.js|kit.css`: места с картой, обратный отсчёт, календарь (.ics), появление при прокрутке. Описание шаблона (тексты, места под фото, палитра, `premium`) — в `shared/templates.js`. Обложка 540×720 — `templates/_covers/<id>.jpg`.

## Устройство

```
shared/     бизнес-логика: API-ядро и тарифы (core.js), модель данных (model.js), каталог шаблонов, демо-данные
server/     Node-сервер без зависимостей: API, страницы /i/:slug, оплата (yookassa.js), почта (mailer.js),
            оферта и политика (legal.js), настройки (config.js)
web/src/    интерфейс на React 19 (сборка esbuild)
web/public/ шаблоны, картинки, рантайм шаблонов
deploy/     Caddyfile (HTTPS), скрипт внешних бэкапов
test/       автотесты: npm test
```

Хранилище — `data/db.json` (атомарная запись с fsync, ежедневные копии в `data/backups`, дозапись при остановке) и `data/uploads`. Этого хватает на тысячи пар; при росте замените `store` в `server/index.js` на Postgres — коллекции повторяют `emptyDb()`.

Если сервер недоступен (статический хостинг), интерфейс запускает то же ядро в браузере поверх IndexedDB — это демо-режим для витрины.

## Разработка

```sh
npm install
npm run build
npm start          # http://localhost:3000, демо-вход demo@wednello.ru / demo123
npm test
```

Без SMTP письма печатаются в консоль. Без ЮKassa оплата отвечает «не подключена».
